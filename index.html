Тестирование на телефоне / Получить .APK

Сборка, мгновенная отправка в Telegram и проверка нововведений на смартфоне

💡
Самый быстрый способ тестировать на реальном Android: укажите токен Telegram-бота и ваш Chat ID. Файл APK прилетит прямо в ваш чат в Telegram на телефоне. Просто нажмите на полученный файл — и приложение обновится!
Готов к отправке на телефон.
❓ Как за 1 минуту создать своего бота для отправки APK?

1. Откройте в Telegram официального бота @BotFather и отправьте команду /newbot.

2. Задайте имя (например: MyTestApkBot) и скопируйте выданный HTTP API Token.

3. Нажмите /start в созданном вами боте, чтобы разрешить ему присылать вам сообщения.

4. Чтобы узнать свой Chat ID, перейдите в бота @userinfobot — он мгновенно покажет ваш числовой ID.

⚡
Полная автоматизация через закрытый GitHub репозиторий: Мы создали для вас файл .github/workflows/build-and-send-apk.yml. Теперь при каждом коммите GitHub бесплатно собирает APK и присылает его вам на телефон!
1 Добавьте секреты в репозитории на GitHub:

Откройте ваш репозиторий -> Settings -> Secrets and variables -> Actions -> кнопка New repository secret:

  • TELEGRAM_BOT_TOKEN — токен от @BotFather
  • TELEGRAM_CHAT_ID — ваш числовой ID
2 Сделайте коммит в репозиторий:

Достаточно сделать git push. GitHub Actions сам запустит виртуальную машину с Java 17, скомпилирует Android APK и через 2 минуты пришлет файл вам в Telegram!

3 Скачивание из вкладки Actions:

Даже без Telegram, файл всегда доступен в GitHub: вкладка Actions -> кликните на последний запуск -> блок Artifacts -> psl-analyzer-debug-apk.

📲
Мгновенное тестирование на смартфоне прямо сейчас: Не хотите ждать сборки APK? Откройте приложение на телефоне через камеру по QR-коду — камера 720p 30 FPS, 11 условий коуча и MediaPipe FaceMesh работают на 100% идентично!
Наведите камеру смартфона

Откройте ссылку в браузере Google Chrome Android для полного аппаратного ускорения камеры.

--
⭐ Лайфхак для установки как нативное приложение: открыв ссылку на телефоне в Google Chrome, нажмите меню ⋮ -> «Установить приложение» (или «Добавить на главный экран»). Приложение установится на домашний экран с иконкой и будет работать во весь экран без адресной строки!
Сборка APK на вашем компьютере:
npm run build:apk

Собирает Vite проект, синхронизирует Capacitor и компилирует Debug APK через Gradle.

Установка на телефон через USB кабель (ADB):
adb install -r android/app/build/outputs/apk/debug/app-debug.apk

Подключите телефон по проводу с включенной в настройках разработчика "Отладкой по USB".

Раздача APK по локальному Wi-Fi:
npm run serve:apk

Запускает локальный сервер на порту 3030 и выводит QR-код в консоль для прямого скачивания APK на смартфон.
